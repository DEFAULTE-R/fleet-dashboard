# 🚀 Fleet Monitoring Dashboard

A real-time monitoring system for industrial devices built using FastAPI, SQLite, and a live frontend.

---

## 🔥 Features

- Real-time device simulation
- Live dashboard updates
- Health classification:
  - 🟢 Healthy
  - 🟡 Warning
  - 🔴 Error
- Automatic alert generation
- Lightweight backend (FastAPI + SQLite)

---

## 🛠️ Tech Stack

- **Backend:** FastAPI (Python)
- **Database:** SQLite
- **Frontend:** HTML + JS (live updates)
- **Simulation:** Python script
