## 🌐 Live Demo
https://fleet-dashboard-hc0y.onrender.com/

---

## 📌 Overview
A real-time fleet monitoring system that simulates device telemetry, processes it through a FastAPI backend, and visualizes system health, alerts, and anomalies via a live dashboard.

---

## 🚀 Features
- 📊 Real-time device monitoring
- 🧠 Health scoring system (0–100)
- 🚨 Alert generation (overheat, error spikes)
- ✅ Alert resolution system
- ⚠️ Anomaly detection (behavior-based, not just thresholds)
- 📈 Live charts for temperature, CPU, memory
- 🌐 Deployed backend (Render)
